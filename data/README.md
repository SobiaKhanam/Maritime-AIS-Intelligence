# Data

`ais_demo.csv` and `ais_sample_100.csv` are **fully synthetic** and are not MarineTraffic records. Synthetic coordinates, vessel IDs, movement and timestamps are simulated for demonstration.

The original 43,283-record MarineTraffic export is not included. The published research summary describes analysis of that private export, which cannot be reproduced from the demo file. To rerun on an authorized copy, place it at `data/ais.csv` and pass that path to the CLI.
